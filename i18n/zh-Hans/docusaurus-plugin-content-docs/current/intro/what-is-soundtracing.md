# Sound Tracing 是什么？

**Sound Tracing** 是一种基于物理的技术，用于模拟虚拟空间中声源到达听者的声学传播路径。
它是光线追踪（ray tracing）在声学领域的对应方法，以几何方式处理反射、绕射、透射、吸收等现象，
从而重现空间自身的听感。

![路径可视化](/img/intro/path-visualization.png)

## 解决什么问题

- **有空间感的声音**：根据空间信息（几何体与材质）生成脉冲响应（IR），让同一个声源在洞穴、
  音乐厅、巷道中听起来各不相同。
- **实时响应**：当听者、声源或环境变化时更新 IR，以适合游戏、VR、模拟器的延迟提供结果。
- **基于物理的一致性**：不依赖启发式混响预设，而是使用直接从几何体推导出的结果，
  因此能自然适应场景变化。

## 如何工作

![Sound Tracing 概念图](/img/intro/pipeline-concept.png)

1. **场景输入**：接收网格、材质（9 频段反射/吸收/透射/散射）、声源与听者位置。
2. **路径追踪**：用从听者发出的 guide ray 和镜像声源验证找到直达声、透射、镜面反射路径，
   并在网格棱边（wedge）上求解 UTD 绕射路径。从声源发出的 transport ray 收集漫散射和房间统计量
   （平均自由程、表面积、材质分布），用于驱动 late reverb。
3. **IR 转换**：把到达路径的延迟、Doppler、9 频段能量和方向信息转换到声学域，并执行把早期反射
   拆分为 exact 对象和 HOA3 bed 的 **Hybrid** 聚合。
4. **渲染**：经过频段延迟环 → 路径 tap → 空间化（HRTF / 声像 / 扬声器）→ FDN16 late reverb → 限制器，
   生成实时立体声/N 声道输出或确定性 IR。

这条管线的现行实现就是 [SimpleST](../core/simplest.md) 引擎，所有 SDK 和中间件插件都运行在它之上。
