# 产品线

Sound Tracing 产品线由 **Core 引擎**、**SDK 绑定** 和 **分析工具** 三个部分组成。

## Core

基于 C/C++ 的原生声学仿真引擎。

- [STCoreV2](../core/stcorev2.md) — 模块化 path module 与 lock-free 数据流的原生 core

## SDK

让 Core 引擎可在各平台/语言中使用的绑定阵列。

- [SDK 概览](../sdk/overview.md)
- 已提供：Web、Unity、Unreal Engine
- 计划中：Python

## ExaTools

用于 IR 分析、数据转换、批量验证等工作的工具集。

- [ExaTools 概览](../exatools/overview.md)
