# IRAnalyzer

**Room Impulse Response (IR) analysis and visualization tool.**

IRAnalyzer validates the accuracy of IRs generated by the Sound Tracing geometric-acoustics simulator
and compares them against measured data and results from other simulators. It consists of two
executables.

:::note
IRAnalyzer's option for connecting a real-time simulation backend was written against the STCoreV2
source tree. Using the SimpleST offline ABI (`SimpleSTOffline`) as a backend is separate work; until
then, load the pressure IRs (WAV) generated by SimpleST as external IRs and analyze them.
:::

## Components

| Module | Executable | Description |
|---|---|---|
| **simulator** | `rir_sim` | Standalone Embree-based path-tracing IR synthesizer (validation baseline) |
| **viewer** | `rir_viewer` | Real-time visualization and analysis tool based on SDL3 + ImGui |

## Build

### Requirements

- CMake 3.20+
- C++20-compatible compiler
- macOS 13.0+ (Apple platforms are supported first)

Most dependencies are downloaded automatically through CMake `FetchContent`.

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

### Optional dependencies

| Dependency | CMake variable | Use |
|---|---|---|
| Intel Embree 4 | (system install) | `rir_sim` path tracing |
| STCoreV2 source (legacy) | `STCORE_SOURCE_DIR` | Old real-time simulation backend |
| SketchUp C SDK | `SKETCHUP_SDK_DIR` | Direct `.skp` file loading |

```bash
# add the SketchUp SDK
cmake -S . -B build \
  -DSKETCHUP_SDK_DIR=/path/to/sketchup-sdk-mac \
  -DCMAKE_BUILD_TYPE=Release
```

### Tests

```bash
cd build && ctest
```

## Viewer (`rir_viewer`)

Runs as a multi-panel interface based on ImGui docking.

| Panel | Function |
|---|---|
| **3D Viewport** | Scene geometry, acoustic paths, debug visualization |
| **Control** | Simulation parameters (ray resolution, max depth, tuning) |
| **View** | Scene statistics, rendering options (wireframe, face culling) |
| **Materials** | Per-band absorption and scattering coefficients, automatic BRAS CSV mapping |

## Simulator (`rir_sim`)

A **standalone** synthesizer that uses Embree directly to trace paths and synthesize IRs. It serves as
the *reference* for validating accuracy by comparing results with SimpleST under the same scene and
material conditions.

## Use scenarios

- **Regression validation** — check IR differences before and after engine changes
- **Algorithm comparison** — deterministic tracing (rir_sim, Embree) vs. statistical acoustic propagation (SimpleST)
- **Material tuning** — visualize immediately after adjusting per-band absorption
- **Measurement comparison** — overlay measured and simulated IRs on the same axes (based on BRAS CR2 ~ CR4)
