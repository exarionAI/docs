# Sound Tracingとは?

**Sound Tracing**は、仮想空間内の音源からリスナーへ到達するまでの音響伝搬経路を
物理ベースでシミュレーションする技術です。光のレイトレーシング（ray tracing）に対応する
音響領域のアプローチで、反射・回折・透過・吸収といった現象を幾何学的に扱い、空間が
持つ固有の聴こえ方を再現します。

![経路の可視化](/img/intro/path-visualization.png)

## 解決すること

- **空間感のあるサウンド**: 同じ音源でも洞窟、コンサートホール、路地で異なって聞こえるように、
  空間情報（ジオメトリ・材質）を反映したインパルス応答（IR）を生成します。
- **リアルタイム応答**: リスナー・音源・環境が変化したときにIRを更新し、ゲーム・VR・シミュレーターに
  適用できる遅延時間で結果を提供します。
- **物理ベースの一貫性**: ヒューリスティックなリバーブプリセットではなく、ジオメトリから直接導かれた
  結果を使うため、シーンの変化に自然に適応します。

## 動作の流れ

![Sound Tracing 概念図](/img/intro/pipeline-concept.png)

1. **シーン入力**: メッシュ・材質（9バンドの反射/吸収/透過/散乱）・音源・リスナー位置を受け取ります。
2. **経路追跡**: リスナーから放つ guide ray とイメージソース検証で直接音・透過・鏡面反射経路を見つけ、
   メッシュのエッジ（wedge）で UTD 回折経路を解きます。音源から放つ輸送レイは拡散散乱とルーム統計
   （平均自由行程、表面積、材質分布）を集めて late reverb を駆動します。
3. **IR変換**: 到達経路の遅延・Doppler・9バンドエネルギー・方向情報を音響ドメインへ変換し、
   初期反射を exact オブジェクトと HOA3 bed に分ける **Hybrid** 集約を行います。
4. **レンダー**: バンド遅延リング → 経路タップ → 空間化（HRTF / パンニング / スピーカー）→ FDN16 late reverb → リミッターを
   経て、リアルタイムのステレオ・Nチャンネル出力、または決定的なIRを生成します。

このパイプラインの現行実装が [SimpleST](../core/simplest.md) エンジンであり、すべてのSDKとミドルウェアプラグインが
その上で動作します。
