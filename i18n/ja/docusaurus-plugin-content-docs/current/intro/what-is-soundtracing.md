# Sound Tracingとは?

**Sound-Tracing** は、世宗大学校の [朴宇燦（Woo-Chan Park）教授](https://prof.sejong.ac.kr/pwchan/index.do) 研究チームが
研究・開発したサウンドトレーシング論文に基づいて作られたリアルタイム空間音響ソリューションです。

光のレイトレーシング（ray tracing）に対応する音響領域のアプローチで、反射・回折・透過・吸収といった現象を
幾何学的に扱い、空間が持つ固有の聴こえ方を再現します。

![経路の可視化](/img/intro/path-visualization.png)

## 解決すること

- **空間感のあるサウンド**: 同じ音源でも洞窟、コンサートホール、路地で異なって聞こえるように、
  空間情報（ジオメトリ・材質）を反映したインパルス応答（IR）を生成します。
- **リアルタイム応答**: リスナー・音源・環境が変化したときにIRを更新し、ゲーム・VR・シミュレーターに
  適用できる遅延時間で結果を提供します。
- **物理ベースの一貫性**: ヒューリスティックなリバーブプリセットではなく、ジオメトリから直接導かれた
  結果を使うため、シーンの変化に自然に適応します。

## 動作の流れ

![Sound Tracing 概念図](/img/intro/pipeline-concept.png)

1. **シーン入力**: メッシュ・材質（9バンド）・音源・リスナー位置を受け取ります。
2. **経路追跡**: 直接音・透過・反射・回折の経路を見つけ、空間の拡散特性を集めて late reverb を駆動します。
3. **IR変換**: 到達経路の遅延・Doppler・バンドエネルギー・方向情報を音響ドメインへ変換します。
4. **レンダー**: バイノーラル（HRTF）・パンニング・スピーカーレイアウトでリアルタイム出力、または決定的なIRを生成します。
