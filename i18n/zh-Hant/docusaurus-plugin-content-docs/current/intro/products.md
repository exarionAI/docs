# 產品線

Sound Tracing 產品線由 **Core 引擎**、**SDK 綁定** 和 **分析工具** 三個部分組成。

## Core

基於 C/C++ 的原生聲學模擬引擎。

- [STCoreV2](../core/stcorev2.md) — 具備模組化 path module 與 lock-free 資料流的原生 core

## SDK

讓 Core 引擎可在各平台/語言中使用的綁定陣列。

- [SDK 概覽](../sdk/overview.md)
- 已提供：Web、Unity、Unreal Engine
- 規劃中：Python

## ExaTools

用於 IR 分析、資料转换、批量驗證等工作的工具集。

- [ExaTools 概覽](../exatools/overview.md)
