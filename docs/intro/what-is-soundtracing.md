# Sound Tracing이란?

**Sound-Tracing**은 세종대학교 [박우찬 교수](https://prof.sejong.ac.kr/pwchan/index.do) 연구진이 연구·개발한
사운드 트레이싱 논문을 기반으로 만든 실시간 공간 음향 솔루션입니다.

빛의 광선 추적(ray tracing)에 대응하는 음향 영역의 접근으로, 반사·회절·투과·흡수 같은 현상을
기하학적으로 다루어 공간이 가지는 고유한 청감을 재현합니다.

![경로 시각화](/img/intro/path-visualization.png)

## 무엇을 해결하는가

- **공간감 있는 사운드**: 같은 음원이라도 동굴, 콘서트홀, 골목길에서 다르게 들리도록
  공간 정보(지오메트리·재질)를 반영한 임펄스 응답(IR)을 생성합니다.
- **실시간 응답**: 청취자·음원·환경이 변할 때 IR을 갱신하여 게임·VR·시뮬레이터에
  적용 가능한 지연 시간으로 결과를 제공합니다.
- **물리 기반 일관성**: 휴리스틱한 리버브 프리셋 대신 지오메트리에서 직접 유도된
  결과를 사용하여 장면 변화에 자연스럽게 적응합니다.

## 어떻게 동작하는가

![Sound Tracing 개념도](/img/intro/pipeline-concept.png)

1. **장면 입력**: 메시·재질(9밴드)·음원·청취자 위치를 받습니다.
2. **경로 추적**: 직접음·투과·반사·회절 경로를 찾고, 공간의 확산 특성을 모아 late reverb를 구동합니다.
3. **IR 변환**: 도달 경로의 지연·Doppler·밴드 에너지·방향 정보를 음향 도메인으로 바꿉니다.
4. **렌더**: 바이노럴(HRTF)·패닝·스피커 레이아웃으로 실시간 출력 또는 결정적 IR을 만듭니다.
