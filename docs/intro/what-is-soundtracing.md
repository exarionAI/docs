# Sound Tracing이란?

**Sound Tracing**은 가상 공간 내 음원이 청취자에게 도달하기까지의 음향 전파 경로를
물리 기반으로 시뮬레이션하는 기술입니다. 빛의 광선 추적(ray tracing)에 대응하는
음향 영역의 접근으로, 반사·회절·투과·흡수 같은 현상을 기하학적으로 다루어 공간이
가지는 고유한 청감을 재현합니다.

![경로 시각화](/img/intro/path-visualization.png)

## 무엇을 해결하는가

- **공간감 있는 사운드**: 같은 음원이라도 동굴, 콘서트홀, 골목길에서 다르게 들리도록
  공간 정보(지오메트리·재질)를 반영한 임펄스 응답(IR)을 생성합니다.
- **실시간 응답**: 청취자·음원·환경이 변할 때 IR을 갱신하여 게임·VR·시뮬레이터에
  적용 가능한 지연 시간으로 결과를 제공합니다.
- **물리 기반 일관성**: 휴리스틱한 리버브 프리셋 대신 지오메트리에서 직접 유도된
  결과를 사용하여 장면 변화에 자연스럽게 적응합니다.

## 어떻게 동작하는가

![Sound Tracing 개념도](/img/intro/pipeline-concept.png)

1. **장면 입력**: 메시·재질(9밴드 반사/흡수/투과/산란)·음원·청취자 위치를 받습니다.
2. **경로 추적**: 청취자에서 쏜 guide ray와 이미지 소스 검증으로 직접음·투과·정반사 경로를 찾고,
   메시 모서리(wedge)에서 UTD 회절 경로를 풉니다. 음원에서 쏜 수송 레이는 확산 산란과 룸 통계
   (평균 자유 경로, 표면적, 재질 분포)를 모아 late reverb를 구동합니다.
3. **IR 변환**: 도달 경로의 지연·Doppler·9밴드 에너지·방향 정보를 음향 도메인으로 바꾸고,
   초기 반사를 exact 오브젝트와 HOA3 bed로 나누는 **Hybrid** 집계를 수행합니다.
4. **렌더**: 밴드 지연 링 → 경로 탭 → 공간화(HRTF / 패닝 / 스피커) → FDN16 late reverb → 리미터를
   거쳐 실시간 스테레오·N채널 출력 또는 결정적 IR을 만듭니다.

이 파이프라인의 현행 구현이 [SimpleST](../core/simplest.md) 엔진이며, 모든 SDK와 미들웨어 플러그인이
그 위에서 동작합니다.
